**:DEPENDENCIES:**



mysql-connector-python

tabulate



**:Software Requirements:**

MySQL v8.0.39 (or higher)

Python 3.14 (or higher)

Python-MySQL connector



Program has been tested on system running Windows 11(Build 26200.7462)



Features:

>>>Uses SQL integration to store user data and allow multi-user access simultaneously.

>>>User login system, credential management with roles distributed as per user class.

>>>Management of Patient Directory(Prescriptions, Beds, including past prescriptions and history)

>>>Cart-based Pharmacy and billing

>>>Employee management(Entries for Doctor, Pharmacist in v1.1)

>>>Coloured menu elements for better UX



NOTE:

Run in any command shell for best experience, not the default IDE shell.
